# PM-02: JavaScript Programme

## Project
A simple Support Ticket Priority Checker demonstrating JavaScript fundamentals.

## Features
- Variables, strings, numbers and Booleans
- Arithmetic operators and a calculated total
- Conditions and a reusable function
- An array displayed with a `for...of` loop
- Form input and a priority result

## Run the project
1. Download or clone this repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Enter a ticket description, select an issue category, and choose the number of days waiting.
4. Select **Check priority**.

## Files
- `index.html` — page structure
- `style.css` — page styling
- `script.js` — JavaScript functionality
